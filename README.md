# 🎱 ШАРОБОЙ

Аркадный разбиватель: вместо кирпичей — шары и овалы, ракетка с закруглёнными
углами. Управляй шаром, разбивай фигуры, собирай бонусы (и уворачивайся от
вредных!) и пробивайся к финальному боссу.

## Возможности

- **Кампания из 4 уровней** с финальным боссом «Царь-шар» — у босса несколько
  фаз, а из него во время боя падают только вредные бонусы.
- **Бесконечный режим** с сидом дня — у всех игроков одинаковый уровень,
  соревнуйся в мировом топе.
- **Бонусы двух типов**: полезные (широкая ракетка, щит, лазер, ракеты,
  мультишар) и вредные (ускорение шара, узкая ракетка) — падают с неба,
  успей поймать нужный.
- **Магазин прокачки** — трать монеты на постоянные улучшения.
- **12 достижений** с тостами в игре и витриной в меню.
- **Мировая таблица рекордов** (Supabase):
  - периоды — за день, за месяц, за всё время;
  - отдельные рейтинги для кампании и бесконечного режима;
  - категории по типу экрана — 📱 мобильные, 🖥 FHD, 4K (честная конкуренция);
  - у каждого игрока одна лучшая запись, ники проходят фильтр.
- **Локальные рекорды** с никами — отдельно для кампании и бесконечного режима.
- **Адаптация под любой экран**: весь мир игры масштабируется под экран одним
  коэффициентом — на телефоне, FHD и 4K объекты имеют одинаковый относительный
  размер, отдельной подстройки баланса не требуется; блоки не пересекаются
  на любых пропорциях поля.
- **PWA**: работает офлайн, устанавливается на телефон и компьютер.
- **Звук** — синтезируется на лету через WebAudio, без аудиофайлов.
