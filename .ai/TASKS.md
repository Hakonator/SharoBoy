# Задачи (TASKS)

Здесь живут только актуальные задачи. Формат карточки описан в шапке
`.clinerules`; выполненные задачи удаляются — короткая сводка их результатов
остаётся в `.ai/STATE.md` (раздел «Текущая фаза») и в `memory-bank/progress.md`.

Правила ведения файла:

1. Подробные карточки сохраняются для **трёх последних** выполненных задач
   (чтобы архитектор мог перепроверить реализацию по acceptance criteria).
2. Более ранние выполненные карточки удаляются; в конце файла — таблица-архив
   «Выполнено ранее» со ссылкой на соответствующую запись в `.ai/STATE.md`.
3. Готовые к работе задачи (`ready`) идут первыми; заблокированные (`blocked`)
   — отдельным разделом с описанием блокера.
4. Если файл вырос больше ~600 строк — удаляй самые старые из трёх подробных
   карточек, оставляя строку в архиве.

### T-063: Доработка минибоссов — три щитка панциря, клешни-пинцеры, разворот угря

Status: done · Priority: high (визуальный дефект) · Сложность: M · Зависимости: T-058 · Доработка

Дефекты (по приёмке пользователя):

1. Краб: вместо трёх пластин панциря на спине читался один купол; клешни —
   эллипс с вырезом, на настоящие не похожи.
2. Угорь: двигался задом (голова всегда вправо), хвост из двух вращающихся
   лопастей — «ножницы», у стены не разворачивался, при появлении круга
   телеграфа телепортировался в сторону.

Сделано:

- **Краб** (`minibosses.ts` + `render/minibossCrab.ts`): пластины разнесены
  (±40 / 0), у каждой свой щиток с килем, заклёпками и тёмным швом по нижней
  кромке, центральная рисуется поверх боковых. Клешня — пинцер: «предплечье»,
  ладонь, неподвижный крюк и подвижный дактиль (открывается по `time`), левая
  клешня — зеркальная копия правой (`ctx.scale(outward, 1)`). Ноги — четыре пары
  из двух сегментов.
- **Угорь** (`minibosses.ts` + `types.ts` + `game/minibossRuntime.ts` +
  `render/minibossEel.ts`): силуэт зеркально симметричен (нос/хвост одинакового
  размера), направление — новое поле `Block.mbFacing`, которое рантайм считает
  по сдвигу центра за кадр с мёртвой зоной 0.05 px; рендер отражает силуэт
  через `ctx.scale(facing, 1)` → нос всегда по ходу движения, у стен существо
  разворачивается. Тело — цельный контур с сужением к хвосту, спинной и
  подхвостовой гребни, боковая линия, голова с пастью/глазом/жаберной щелью,
  хвост — одна замкнутая форма с узким плавником.
- **Рывок без телепорта** (`game/blockMotion.ts` + `game/minibossRuntime.ts`):
  `stepBlock` пишет на блоки `mbSwayOffset` и диапазон `mbSwayMin/mbSwayMax`;
  `moveCreatureGroup` считает `b.x = b.x0 + clamp(sway + dash)` — смещение
  складывается с патрулём, а не заменяет его. Суммарный сдвиг клампится
  стенами поля.
- **Живой центр**: `creature.dropX/dropY` обновляются каждый кадр, поэтому круг
  телеграфа, осколки и дроп жизни появляются там, где существо находится, а не
  где родилось.

Тесты (+9, новый файл):

  (знак `m[0]` в матрице красок), цельный контур тела (до первой заливки нет
