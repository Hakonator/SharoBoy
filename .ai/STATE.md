**Фикс №8 (24.10.2026) — объёмное тело миноги и живой глаз**:
жалоба «тело миноги выглядит простой толстой линией; глаз пусть моргает и следит
за шаром». Причина плоскости: тело рисовалось ДВУМЯ линиями (`stroke`) постоянной
ширины 22/12 px — контур не зависел от радиусов сегментов, поэтому силуэт был
трубой. Теперь:

- новый `lampreyBodyPath(ctx, pts, radii, edge)` строит **замкнутый силуэт** из
  оси (центры сегментов) и нормалей, полуширина берётся из `b.rx` — тело сужается
  к хвосту ровно как хитбоксы. Один путь переиспользуется для всех слоёв
  (`edge` = 1.18 тень / 1.0 кожа / 0.82 тело / 0.34 спинной блик), поэтому слои
  не «разъезжаются» (правило «геометрия одной фигуры — из одних формул»);
- слои: тень на дне → тёмная кожа с обводкой → заливка `linearGradient`
  «спина → брюхо» (в злой фазе малиновая) → светящаяся спинная полоса
  (`shadowBlur`) → перетяжки между позвонками (квадратичные дуги) → хвостовой
  плавник;
- новый `drawLampreyEye()`: склера, радиальная радужка, зрачок и блик; зрачок
  смещается к **ближайшему шару** (ограничение `r*0.45`, чтобы не вылезал), а
  моргание — цикл 3.6 с со сдвигом по seed (веко-эллипс + ресница). Если шаров
  нет, взгляд уходит в свободное движение по `bo.t`;
- `drawLampreyBoss` получил параметр `balls` (прокинут из `drawBoss`).

Заодно убран мёртвый `lampreyRevive` из `types.ts` (остался от удалённого регена).

**Фикс №6 (24.10.2026, ГИБРИД по решению пользователя) — итоговая механика миноги**:
жалоба «после убийства миноги она снова появляется и становится неубиваемой»
вскрыла корень всех прошлых правок: **голова была не целью победы, а «замком»**.
Урон по HP шёл только при `headAlive && headExposed`, поэтому сбитая голова
(самый заметный элемент — игрок бьёт именно её) давала «визуальную смерть» без
снятия HP, а через 6 с реген её возвращал — босс выглядел воскресшим и
неубиваемым. Итоговая схема:

- **голова — смертельная точка**: `stepLamprey` при отсутствии сегмента 0
  вызывает новый `BossHost.killBoss()` → штатный `BossSystem.kill()` (цепочка
  взрывов, уборка арены, дроп). Регена больше нет: `reviveLamprey`,
  `HEAD_REGEN_TIME` и кольцо реваншa в рендере **удалены**.
- **хвост — бонус, а не замок**: новый `lampreyDamageMult(blocks)` — урон идёт
  всегда, но защищённое тело принимает его ослабленным (×1/7 при целом хвосте,
  ×1 при ≥3 сбитых). Бой нельзя «заблокировать», но выгодно разбирать броню.
- Причина тупиков №4/№5 устранена архитектурно: босс не может остаться без
  головы и жить дальше, поэтому невозможны ни «невидимый неуязвимый босс», ни
  бесконечный реген. Тесты переписаны: «сбитая голова убивает сразу»,
  «целый хвост ослабляет, но не блокирует», «урон идёт, хвост ускоряет
  добивание», «полный проход боя до победы». Проверки: typecheck чист, eslint 0,
  prettier чист, 70 файлов / 553 теста.

**Фикс №5 (24.10.2026, решение пользователя — вариант A)**: фикс №4 убрал тупик,
но сделал бой нечестным: полный реген тела каждые 6 с обнулял работу игрока
(8 сегментов × HP 5/4/4/3/3/2/2/2 = 25 ударов по кругу). Итоговая механика:
**сбитый хвост не восстанавливается, отрастает только голова**. `reviveLamprey(g)`

архитектурно: чем сильнее разобрана броня, тем уязвимее босс. Тесты
(`bossDiagnostics.test.ts`, 3 кейса): «отрастает только голова, бой можно
добить» (HP снимается), «сбитый хвост не возвращается» (`[0,4,5,6,7]`),

чист, eslint 0, prettier чист, 70 файлов / 554 теста.
