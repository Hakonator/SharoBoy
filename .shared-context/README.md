# Shared Context Between AI Assistants

## Как работает координация

### Cline + Luna (Исполнитель)

- Пишет код
- Реализует задачи из .ai/TASKS.md
- Запускает тесты
- Коммитит изменения

### Antigravity + Gemini (Архитектор)

- Читает .ai/TASKS.md и .ai/STATE.md
- Создаёт новые задачи
- Проверяет реализацию через git diff
- Обновляет архитектуру

## Правила синхронизации

1. Перед началом работы каждый ассистент читает:
   - .ai/STATE.md
   - .ai/TASKS.md
   - .handoff/FEATURE_STATUS.md

2. После работы каждый ассистент обновляет:
   - .ai/STATE.md (текущий статус)
   - .ai/TASKS.md (если задачи изменились)
   - Git commit с понятным сообщением

3. Коммиты должны быть маленькими и атомарными
4. Одна задача = один коммит
