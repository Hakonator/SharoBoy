- **Данные** `blockKinds.ts`: интерфейс `BlockSpecial` (поле `Block.sp`) + константы
  баланса (PULSE_AMPLITUDE, SPRING/COTTON_SPEED_MULT и времена, PORTAL_CD, SPIN_KICK/MAX).
  `Ball` получил таймеры `springT`/`cottonT`.
- **Маршрутизатор траекторий** `game/blockMotion.ts` (`stepBlock`): старые
  sway/bob перевезены из `updateStep` + новые маршруты дрейфа (горизонталь /
  вертикаль / окружность с эллипсом 0.6), пульсация размера (хитбокс следует
  за визуалом — collideBlocks читает rx/ry), интеграция вращения с трением
  (exp(-1.1·dt), отсечка <0.02), тик кулдауна порталов.
- **Эффекты удара** `physics/special.ts` (`onBallHitSpecial` из `collideBlocks`
  до отражения): пружина/вата ставят таймеры на шаре (звук+бёрст), повторный
  удар не перезапускает активный таймер; крутящийся получает угловой импульс
  от стороны и глубины удара (кламп SPIN_MAX); телепорт поглощает контакт:
  переброс к живому партнёру по вектору скорости, кулдаун на всю пару,
  сброс хвоста шара. Множители применяются в `Physics.updateBall` через
  `specialSpeedMult`.
- **Расстановка** `game/blockSpawn.ts` (`decorateBlocks` из `buildFromSpec`,
  кроме боссовых арен): детерминированно из seed (кампания — seed уровня,
  бесконечный — daySeed-волна); интенсивность `specialIntensity` = 0 до 3-го
  уровня, растёт до 0.55; каждый блок — максимум один спецтип; порталы — пары
  с общим id и hp 2 (с 4-го уровня, вторая пара с 9-го); исключены минибоссы,
  щупальца, орбитальные и бомбы; дрейф отключает сеточное sway; крутящийся —
  только вытянутые некруглые.
- **Рендер** `render/blockKinds.ts`: кастомные тела пружины (сжатие при ударе
  через flash), ваты (пушистое облако), портала (тёмное ядро + вращающееся
  аккреционное кольцо, тускнеет на кулдауне) — градиенты через gradCache;
  метки поверх стандартного тела: кольцо пульсации, штрихи маршрута, стрелки
  вращения.
- **Звук** `audio.ts`: `spring()` (бо-инг вверх), `thud()` (глухой шлепок),
  `warp()` (воронка-свип).
- Тесты: `blockMotion.test.ts` (9), `special.test.ts` (11), `blockSpawn.test.ts`
  (8): маршруты/пульсация/вращение/кулдаун, семантика ударов, пары порталов,
