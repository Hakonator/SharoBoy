## Следующие шаги (задачи на завтра, 24.09.2026)

**Тема 1 — новые типы блоков (ROADMAP §6, приоритет 2):**

1. **Пульсирующий** — плавно циклично меняет размер (масштаб rx/ry по синусоиде,
   хитбокс пересчитывается каждый кадр; seeded-фаза из `seed` блока).
2. **Пружинный** — удар временно **ускоряет шар** (переиспользовать
   `physics/speed.ts`-механику локального таймерного множителя); отскок с
   пружинной анимацией сжатия-расжатия.
3. **Ватный** — удар временно **замедляет шар**; мягкая анимация, глухой звук.
4. **Крутящийся** — продолговатый блок: удар в одну из половин раскручивает его
   (`rotVel` от стороны и точки удара, гашение трением); угловая скорость меняет
   нормаль отскока последующих ударов.
5. **Дрейфующий** — траектории: горизонталь, вертикаль в пределах, по окружности;
   обобщить существующие `swayAmp`/`bobAmp` в маршрутизатор траекторий.
6. **Телепортирующий парный (чёрная дыра)** — переброс шара в парный блок с
   сохранением вектора скорости; кулдаун пары против зацикливания; виз/звук
   «воронки».

Технически: расширение `types.ts`/`levelBuilder`/`levelPatterns`, поведение —
чистыми модулями в `src/game/game/` + `src/game/physics/`, рендер —
`render/blocks.ts`; тесты рядом с каждым модулем.
