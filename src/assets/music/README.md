# Музыка (MP3)

Положи треки прямо в эту папку — игра подхватит их автоматически (Vite glob,
файлы попадают в бандл при сборке):

- `src/assets/music/*.mp3` — **общий набор** для меню и партии

## Как работает

- **Треки идут в случайном порядке без повторов**: очередь перемешивается и
  используется целиком, прежде чем начнётся новый цикл. Между циклами последний
  трек не повторяется первым; очередь сохраняется при переходе на карту.
- Смена экрана (старт уровня/волны, выход в меню) берёт следующий трек из очереди.
- **Плавный переход (кроссфейд)**: предыдущий трек гаснет, новый нарастает
  (~0.9 с), резких обрывов нет.
- Когда трек заканчивается — сразу запускается следующий из перемешанной очереди.
- **На карте кампании играет свой трек** — медленная загадочная мелодия
  встроенного секвенсора (не из MP3-набора): игрок проводит там секунды, и
  постоянные переключения треков «бой → карта → бой» только раздражали.
- Кнопка **музыки** (нота) ставит текущий трек на паузу и продолжает с того же
  места; кнопка **звука** (динамик) глушит только эффекты.
- **Если папка пуста** — играет встроенный 8-битный трекер (синтез), как раньше.

## Рекомендации

- Формат MP3, битрейт 128–192 kbps — хватает с запасом.
- Имена файлов — по шаблону `track_XX.mp3` (например `track_01.mp3`,
  `track_17.mp3`): латиница, без пробелов; `XX` — двузначный номер.
- Подпапки не подхватываются: файлы должны лежать в корне этой папки.
