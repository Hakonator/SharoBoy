# Музыка (MP3)

Положи треки в эти папки — игра подхватит их автоматически (Vite glob, файлы
попадают в бандл при сборке):

- `src/assets/music/menu/*.mp3` — для главного меню (медленные, спокойные)
- `src/assets/music/game/*.mp3` — для партии (боевые)

## Как работает

- При смене экрана (меню ↔ игра) играет **случайный трек** из соответствующей
  папки; когда трек заканчивается — запускается следующий случайный (без
  повтора предыдущего, если треков больше одного).
- Кнопка **музыки** (нота) ставит текущий трек на паузу и продолжает с того же
  места; кнопка **звука** (динамик) глушит только эффекты.
- **Если папка пуста** — играет встроенный 8-битный трекер (синтез), как раньше.

## Рекомендации

- Формат MP3, битрейт 128–192 kbps — хватает с запасом.
- Имена файлов — латиницей без пробелов (`track-01.mp3`, `calm-night.mp3`).
